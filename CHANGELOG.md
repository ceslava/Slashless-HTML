# Changelog

## 1.0.0 — 2026-10-27

**English**
- First release of Slashless HTML.
- Formats HTML and writes void elements without the trailing slash (`<img>`, `<br>`…).
- Formatting engine: Prettier 3.8.1, bundled (no installation needed).
- Reads `.prettierrc` (JSON), the `"prettier"` key in `package.json` and VS Code `prettier.*` settings.
- Offers to become the default HTML formatter on first use.
- Interface in English and Spanish.

**Español**
- Primera versión de Slashless HTML.
- Formatea HTML y escribe los elementos vacíos sin la barra final (`<img>`, `<br>`…).
- Motor de formateo: Prettier 3.8.1, incluido (no hace falta instalar nada).
- Lee `.prettierrc` (JSON), la clave `"prettier"` de `package.json` y los ajustes `prettier.*` de VS Code.
- Ofrece convertirse en el formateador de HTML predeterminado la primera vez que se usa.
- Interfaz en inglés y en español.
