# Changelog

## 1.0.0 — 2026-10-26

**English**
- First release.
- Formats HTML with Prettier 3.8.1 (bundled) and removes the trailing slash from void elements.
- Reads `.prettierrc` (JSON), the `"prettier"` key in `package.json` and VS Code `prettier.*` settings.
- Offers to become the default HTML formatter on first use.
- Interface in English and Spanish.

**Español**
- Primera versión.
- Formatea HTML con Prettier 3.8.1 (incluido) y quita la barra final de los elementos vacíos.
- Lee `.prettierrc` (JSON), la clave `"prettier"` de `package.json` y los ajustes `prettier.*` de VS Code.
- Ofrece convertirse en el formateador de HTML predeterminado la primera vez que se usa.
- Interfaz en inglés y en español.
